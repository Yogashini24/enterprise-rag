# Enterprise RAG Platform

A production-oriented Retrieval-Augmented Generation system
for enterprise knowledge retrieval and grounded question answering.

## Goal

Build an end-to-end RAG system covering:

- Data ingestion
- Document processing
- Chunking
- Embeddings
- Vector indexing
- Hybrid retrieval
- Reranking
- Context construction
- Grounded generation
- Evaluation
- Observability
- Production deployment

## Architecture

The system consists of two major pipelines:

1. Knowledge ingestion pipeline
2. Online query and generation pipeline

Detailed architecture will be documented in `docs/architecture/`.
